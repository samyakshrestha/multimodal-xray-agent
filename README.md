# Multi-Agent AI Assistant for Radiology Report Generation

This project presents a **CrewAI-powered multi-agent system** for automated radiology report generation from chest X-rays. Leveraging **vision-language models (VLMs)**, **cross-modal retrieval**, and **modular agent orchestration**, the system mirrors a radiologist’s workflow: it interprets chest X-ray images, retrieves relevant medical literature using semantic similarity search, and synthesizes information from multiple sources to generate coherent, clinically meaningful reports.

## Project Highlights

- **Orchestrated a multi-agent system** with CrewAI, assigning specialized tasks to dedicated agents
- **Developed semantic search pipelines** by embedding IU chest X-ray images with BiomedCLIP and indexing 200,000 PubMed articles using SPECTER2 and FAISS, enabling efficient cross-modal retrieval
- **Integrated Groq API for ultra-fast inference**, achieving >7× lower latency compared to Gemini 2.5 Flash
- **Implemented advanced prompt-engineering techniques** to maximize diagnostic accuracy and optimize multi-agent collaboration
- **Evaluated system performance with LLM-as-Judge and BERTScore**, outperforming single-agent models such as Gemini 2.5 Flash and GPT-4o
- **Deployed the full pipeline on Hugging Face Spaces** via Gradio UI

## Multi-Agent Workflow  

1. **Vision Agent**
   - Uses a **Vision-Language Model (Gemini 2.5 Flash or Llama 4 Maverick)** to generate a detailed caption of the X-ray 
   - Outputs caption in a structured format for downstream agents
2. **Retriever Agent(s)**
    - Pubmed Agnet:
      - Extracts the key medical findings from the caption generated by the Vision Agent
      - Uses **SPECTER2** to generate a **768-D embedding** of the extracted findings
      - Retrieves the **top-k most relevant titles and abstracts** from a **vector database** of 200k PubMed articles using **FAISS**
    - IU Agent:
      - Generates a **512-D embedding** of the X-ray image using **BiomedCLIP**
      - Retrieves the **most similar X-ray image** from the IU dataset via **cosine similarity**
      - Retrieves the **report** corresponding to the most similar image 
3. **Draft Agent** 
    - Synthesizes a detailed radiology report by combining evidence from the Vision and both Retriever agents
4. **Critic Agent**
    - Audits the output of the Draft Agent for factual accuracy and clinical coherence
    - Removes any unsupported or speculative statements to reduce hallucinations
    - Generates the final report in markdown format, with structured sections for findings, impressions, and recommendations

## Technology Stack
- **Frameworks:** CrewAI (multi-agent orchestration), PyTorch, Hugging Face Transformers + Datasets, Gradio
- **LLMs for Reporting:** [Gemini 2.5 Flash], [LLaMA 3.3 70B Instruct], [Llama 4 Maverick], [DeepSeek R1-Distill LLaMA 70B]
- **Image Encoder:** [BiomedCLIP](https://huggingface.co/microsoft/BiomedCLIP-PubMedBERT_256-vit_base_patch16_224) — 512-D image embeddings
- **Text Encoder:** [SPECTER2](https://huggingface.co/allenai/specter2) — 768-D text embeddings
- **Retrieval Infrastructure:** FAISS, cosine similarity search
- **Evaluation:** GPT-4o LLM-as-Judge, BERTScore (semantic similarity)
- **Inference + Deployment:** Groq API (sub-second latency), Hugging Face Spaces (Gradio frontend)
